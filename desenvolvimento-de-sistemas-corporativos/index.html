Desenvolvimento de sistemas corporativos que integram, escalam e não param

Sistemas corporativos são os softwares que sustentam processos críticos de uma empresa, como estoque, pedidos, financeiro, faturamento e operação, e que precisam conversar com ERPs como o SAP, controlar acessos e registrar quem fez o quê. A Ferreiro Corrêa Software desenvolve, integra e moderniza sistemas assim. O fundador, o engenheiro Carlos Eduardo Ferreiro Corrêa, passou oito anos construindo sistemas integrados ao SAP para a Embraer e fez integrações de pagamento para Azul, Gol e TAM.

  • O ERP não cobre o seu processo e a equipe completa o trabalho em planilhas paralelas.

Dúvidas frequentes

Perguntas sobre desenvolvimento de sistemas corporativos

O que é um sistema corporativo?

É um software que sustenta processos centrais de uma empresa, como estoque, pedidos, financeiro, faturamento ou operação, com controle de acesso, registros de auditoria e integração com outros sistemas, como o ERP.

Qual a diferença entre sistema corporativo e ERP?

O ERP é um sistema de gestão pronto, como SAP ou TOTVS, que cobre processos padrão. Um sistema corporativo sob medida cobre o que o ERP não atende, ou do jeito específico da sua empresa, e se integra a ele para os dados não ficarem duplicados.

Vocês fazem integração com SAP?

Sim. O fundador trabalhou oito anos com sistemas integrados ao SAP na Embraer. Também integramos com outros ERPs e serviços que ofereçam API, web services, arquivos ou banco de dados de integração. A viabilidade é avaliada no diagnóstico.

Dá para modernizar um sistema antigo sem parar a operação?

Sim. A migração é feita em etapas: o sistema novo assume uma parte de cada vez enquanto o antigo continua rodando, até a virada completa, com testes e validação a cada etapa.

Como fica a segurança dos dados da empresa?

O sistema é projetado com controle de acesso por perfil, registros de auditoria, criptografia de dados sensíveis, backups e atenção à LGPD desde o início.

Vocês trabalham junto com a equipe de TI da empresa?

Sim. Trabalhamos com a TI interna, com documentação, repositório de código e alinhamento técnico para que a equipe acompanhe e consiga manter o sistema.
