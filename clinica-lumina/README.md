# Clínica Lumina — Site Premium

Site institucional completo para clínica de **Fisioterapia · Psicologia · Fonoaudiologia**.

## Características

- Design arrojado, sofisticado e 100% responsivo
- Tipografia premium (Cormorant Garamond + Outfit)
- Animações suaves de entrada
- Modal LGPD completo (banner + política detalhada)
- Integração direta com WhatsApp (formulário + botões)
- Header sticky com blur
- Botão flutuante WhatsApp
- Mobile menu animado
- SEO básico e performance otimizada

## Como usar

1. Abra `index.html` em qualquer navegador moderno
2. Ou sirva a pasta com um servidor local:
   ```bash
   npx serve .
   # ou
   python -m http.server 8080
   ```

## Personalização rápida

- **Telefone / WhatsApp**: busque por `5511999990000` e substitua
- **Endereço**: seção `#contato`
- **Cores**: variáveis CSS em `css/style.css` (`:root`)
- **Textos da equipe**: cards em `#equipe`
